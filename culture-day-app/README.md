# 2026 문화의 날 부서별 신청·취합

공단 전 부서가 한 페이지에서 2026년 10월 「문화의 날」 참여자를 신청하고, 담당자가 회차별·부서별 현황을 취합할 수 있는 React/Vite 웹앱입니다.

## 반영 일정

- 1회차: 10. 2.(금) / 광주비엔날레 전시 / 광주비엔날레전시관(북구 비엔날레로 111)
- 2회차: 10. 8.(목) / 세계음식 만들기 체험 / 월곡 고려인마을
- 3회차: 10. 16.(금) / 광주비엔날레 전시 / 광주비엔날레전시관
- 4회차: 10. 23.(금) / 세계음식 만들기 체험 / 월곡 고려인마을
- 5회차: 10. 28.(수) / 광주비엔날레 전시 / 광주비엔날레전시관

대상은 공단 전 직원(이사장, 본부장, 일반직, 공무직 등)이며 환경직은 신청 제외 안내를 적용했습니다.

## 주요 기능

- 부서명·담당자·연락처 입력
- 한 부서에서 여러 신청자 일괄 등록
- 직원별 직종 및 희망 회차 선택
- 환경직 신청 차단
- 전체 신청인원, 제출 부서 수, 회차별·부서별 취합 현황
- 부서 필터
- CSV 다운로드
- Supabase 미연결 시 브라우저 localStorage 데모 모드
- Supabase 연결 시 여러 부서가 같은 데이터를 공동 사용

## 실행

```bash
cd culture-day-app
npm install
npm run dev
```

## 전 부서 공동 취합 연결

1. Supabase 프로젝트를 생성합니다.
2. Supabase SQL Editor에서 `supabase/schema.sql` 내용을 실행합니다.
3. `.env.example`을 `.env`로 복사하고 값을 채웁니다.

```bash
cp .env.example .env
```

```env
VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY
```

4. 다시 빌드/배포합니다.

```bash
npm run build
```

## 보안 주의

현재 `supabase/schema.sql`은 빠른 내부 테스트를 위해 익명 insert/select 정책 예시를 포함합니다. 이 상태로 인터넷에 공개하면 이름·담당자 연락처가 조회될 수 있으므로, 실제 운영 배포 전에는 반드시 직원 인증(Supabase Auth 또는 사내 SSO)을 붙이고 조회 정책을 `authenticated` 전용으로 변경하세요.

권장 운영 구조는 다음과 같습니다.

- 일반 직원/부서 담당자: 신청만 가능
- 관리자: 전체 명단·연락처·CSV 조회 가능
- 공개 또는 일반 조회 화면: 부서별/회차별 집계 숫자만 표시

## 배포

Vite 정적 앱이므로 GitHub Pages, Netlify, Vercel 등에 배포할 수 있습니다. 다만 실제 운영 시에는 개인정보 보호를 위해 사내 접근제어 또는 인증이 가능한 호스팅 환경을 권장합니다.
